# CRM Klinik

Aplikasi berbasis web untuk membantu pengelolaan informasi dan proses administrasi klinik. Proyek ini dikembangkan menggunakan Laravel 10 sebagai bagian dari tugas akhir Program Studi Sistem Informasi Bisnis.

## Teknologi yang Digunakan

- **Backend:** PHP, Laravel 10
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Tools:** Git dan GitHub

## Fitur Aplikasi

Fitur aplikasi mengikuti implementasi pada proyek. Bagian ini akan dilengkapi berdasarkan fitur yang benar-benar tersedia, seperti pengelolaan data pasien, jadwal, atau administrasi klinik jika memang sudah diimplementasikan.

## Tujuan Proyek

Proyek ini menjadi penerapan keterampilan dalam pengembangan aplikasi web, pengelolaan basis data, dan perancangan sistem informasi.

## Status Proyek

Proyek akademik. Demo online dan petunjuk instalasi akan ditambahkan setelah persiapan selesai.
